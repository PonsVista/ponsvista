# Contributing

This repository accepts suggestions about documentation, terminology, broken links and public analytics display issues.

## Documentation changes

1. Identify the page or passage that needs correction.
2. Describe the proposed wording and the source supporting it.
3. Keep metric units, time windows and coverage limits explicit.
4. Check relative links and images after the change.

Keep examples free of credentials, private account information and fabricated market values. Use a dated, clearly identified public observation when an example needs numbers.

## Display reports

Use the issue template to provide the affected page, approximate observation time, selected view or pair filter, expected behavior and observed behavior. Remove private account details from any attachment.

This documentation repository does not provide deployment files, application runtime code or transaction execution instructions. A documentation correction should not imply that a production change has already been released.
